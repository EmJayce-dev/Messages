
# Messages with SIM Prompt

An unofficial fork of [Fossify Messages](https://github.com/FossifyOrg/Messages).

Adds a SIM selection popup when sending SMS/MMS messages on dual-SIM Android devices.

### Additional features
- Choose which SIM to use before sending.
- Optionally remember a preferred SIM for individual conversations.
- Change or reset the preferred SIM in Conversation Details.
- Continue asking for a SIM when no preference is saved.
- Single-SIM devices send normally without the chooser.
